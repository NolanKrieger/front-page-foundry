# Sound

Everything in this folder is generated by `tools/audio/build.py` (NumPy + ffmpeg) and is original
work of this project — no recordings, samples or scores from anyone else, so there is nothing to
license and nothing to disclose on the Steam page beyond "procedurally generated audio".

- `rag_*_{piano,banjo,cornet}.ogg` — three ragtime pieces composed by the script from a seed
  (AABBACCDD, oom-pah left hand, syncopated right hand, trio in the subdominant), one stem per
  instrument so the game can bring the banjo and cornet in as the works grows. Pressed to
  "shellac": 250–4500 Hz, wow and flutter, crackle, hiss.
- `sfx_*.ogg` — the GDD §12 effects: press, telegraph, typewriter, bell, pencil, thud, rustle,
  belt (loop), machine (loop), steam (loop), wheel (loop), truck, whistle, horn.
- `manifest.json` — names, durations, loop flags.

Rebuild: `uv run --with numpy python3 tools/audio/build.py` (the rags take about two minutes;
`--sfx-only` skips them). Then `godot --headless --path . --import`. Same seeds, same bytes.
